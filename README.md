# Krea Nova — Real Estate Investments

Plataforma fintech de financiamiento colectivo inmobiliario con derechos económicos representados digitalmente (tokenización RWA) bajo la normativa de la República Argentina.

## Módulos del Sistema

1. **Frontend:** React 19 + TypeScript + Vite + Lucide Icons.
   - Dual-theme (Modo Negro / Modo Blanco con Nordic Porcelain & Deep Obsidian).
   - Onboarding regulatorio con doble perfil (Persona Humana vs Persona Jurídica).
   - Catálogo de oportunidades y cálculo de APY en USD.
2. **Backend:** Go 1.23+ con Arquitectura Hexagonal y Domain-Driven Design (DDD).
